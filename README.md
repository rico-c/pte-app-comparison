> 测评基于各产品公开版本与官方文档，「优秀PTE」部分直接核对了其产品源码。竞品信息为公开信息归纳，非实验室量化评测。AI 评分与模考结果均为备考反馈，不等于 Pearson 正式成绩。

## 各产品简评

### 羊驼PTE
国内知名度最高的 PTE 刷题 App 之一，机经量大、口语评分是主打卖点。但整体体验围绕"背题"设计：练习记录、趋势分析、弱项定位这些复盘环节较薄，进阶提分要靠报它的课程。适合纯靠题海战术的考生。

### 小站PTE
老牌语培机构的产品线，课程 + 题库捆绑销售，中文服务全。平台工具属性弱于课程属性，自主练习的 AI 反馈颗粒度和数据面板不如纯工具型平台。适合本来就打算买课跟着老师走的学生。

### E2Language
澳洲本土口碑很好的 PTE/雅思课程，方法论扎实，有免费试学。但它本质是"课程 + 练习册"，英文界面、澳式辅导，定价按订阅课包走，对习惯中文界面、想自主安排刷题节奏的考生门槛偏高。

### MagoBooks
题库和练习册型产品，题型解析详尽、有评分练习。缺少系统的学习数据面板和考前规划工具，也没有中文本土化体验，更适合作为补充练习资料而非主平台。

### Pearson 官方模考
最接近真实考试的体验，官方计分的付费样卷是检验水平的标尺。但只有两次样卷、没有练习题库、没有弱项分析和复盘工具——它是"尺子"，不是"健身房"。任何人都应该在考前用它校准一次，但不能靠它备考。
